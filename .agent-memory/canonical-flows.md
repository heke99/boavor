# Canonical flows

## Contract to resident

Render exact template snapshot → generate deterministic PDF → private upload →
register SHA-256 immutable version → provider signs exact version → all signers
confirmed → contract signed → tenancy/occupancy/move-in provisioned atomically.

## Maintenance

Active tenant submits validated case → tenant-scoped number → event/outbox →
landlord triage/assignment → work order → completion evidence → tenant verify.

## Exit

Tenant requests termination → landlord confirms contractual date → move-out
case/inspection → keys, damages, settlement and cleaning complete → tenancy ends
→ unit becomes eligible for controlled republication.
