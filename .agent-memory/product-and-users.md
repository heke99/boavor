# Product and users

Bovaro connects shared applicant identities to isolated landlord companies.
Primary actors are applicants, co-applicants, landlord team members, active
tenants, contractors and Bovaro superadmins. A person may hold several
relationships without duplicating identity or leaking data across companies.

Lifecycle: inventory → listing → application → completion/review → viewing →
offer → immutable signed contract → tenancy → move-in → rent/service →
termination → move-out → controlled unit release.
