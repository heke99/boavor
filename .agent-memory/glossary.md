# Glossary

- Company: landlord organization and canonical tenant root.
- Tenancy: resident relationship created from one signed contract.
- Occupancy: person participation in a tenancy.
- Unit: physical rentable home.
- Listing: publication of a unit.
- Outbox: durable transactional queue of domain events.
- Rent ledger: landlord-to-resident receivables, separate from Bovaro billing.
